### Open source

| Repository | What it is |
|---|---|
| [id-hub](https://github.com/spoke1/id-hub) | Staged Conditional Access, identity security and governance baselines for Entra ID, mapped to MITRE ATT&CK, with a drift report |
| [identity-threat-detections](https://github.com/spoke1/identity-threat-detections) | Microsoft Sentinel analytics rules for identity attacks on Entra ID and Active Directory, with semantic KQL validation in CI |

| [zero-trust-iac](https://github.com/spoke1/zero-trust-iac) | Bicep security foundation for Azure subscriptions: security logging, Sentinel, Defender for Cloud, guardrails, OIDC deployment |

The repositories fit together: baselines prevent, detections catch what gets through, and the tooling shows where you stand. Everything is read-only or report-only by default, tested in CI and free of secrets.
